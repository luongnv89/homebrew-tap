# luongnv89/homebrew-tap

Homebrew formulae by [@luongnv89](https://github.com/luongnv89).

```sh
brew install luongnv89/tap/mcc
brew install luongnv89/tap/cmail
```

| Formula | Description |
|---------|-------------|
| [`mcc`](https://github.com/luongnv89/mcc) | Manage multiple Claude Code profiles (accounts) from one CLI |
| [`cmail`](https://github.com/luongnv89/cmail) | Free custom-domain email with Cloudflare Email Routing |

`Formula/mcc.rb` is copied from [`packaging/homebrew/mcc.rb`](https://github.com/luongnv89/mcc/blob/main/packaging/homebrew/mcc.rb) in the mcc repo, which is the source of truth.

`Formula/cmail.rb` is copied from [`packaging/homebrew/cmail.rb`](https://github.com/luongnv89/cmail/blob/main/packaging/homebrew/cmail.rb) in the cmail repo, which is the source of truth.
